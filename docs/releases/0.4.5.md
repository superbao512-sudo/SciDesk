# SciDesk 0.4.5 Ai

本次发布在 0.3.2 的本地科研工作台上加入统一的 SciDesk Ai，并改进 PDF 翻译、期刊推荐、学习资源和教学手册编辑体验。安装名称固定为 **SciDesk**。

## 下载与安装

普通用户下载 **SciDesk_0.4.5_x64-setup.exe**，双击后按中文向导安装。旧版用户先保存工作并退出软件，再选择 **原安装目录** 升级；无需先卸载，原 SciDeskData 和外部科研文件保留。

安装包仅含程序、离线模型、运行库和必需公共资源，不含测试项目、聊天、个人数据库、API 配置或密钥。若系统缺少 WebView2，首次安装该运行环境需要网络；本地 PDF 翻译模型不需要首次下载。

- [安装及旧版本升级说明](https://github.com/superbao512-sudo/SciDesk/blob/main/docs/windows-install-upgrade.md)
- [完整更新记录](https://github.com/superbao512-sudo/SciDesk/blob/main/CHANGELOG.md)
- 使用本页附带的 **SHA256SUMS.txt** 核对文件完整性。
- 安装器未使用代码签名证书签名；SHA-256 用于检查下载完整性，不等同于发行者数字签名。

## 主要变化

- **SciDesk Ai：** 普通聊天和通用 Agent 合并；文献检索保留独立工作区。支持 AI 项目、模型选择、调度／执行／监督角色，以及任务状态和服务商返回的 token 用量。
- **多步文件任务：** 在指令授权范围内创建目录、写文本、复制、移动、重命名和移入回收站；删除、覆盖、批量移动展示目标并确认。简单明确的目录列名走本地工具，减少不必要的模型调用。
- **会话与布局：** 删除会话保留已创建成果；兼容旧聊天记录，列表和对话独立滚动，移除悬浮助手。
- **PDF 离线翻译：** 通用 OPUS 英译中权重随程序内嵌，结合凝聚态术语规则；保留自选 API。
- **近期文献推荐：** 简洁列表、标题展开真实摘要、识别 arXiv；可选最近 1／7／14／30／90 天，按当日日期滚动。
- **学习与手册：** 批量移除学习资源、删除分类；修复手册名称和草稿同步，增加起始页、常用工具栏、章节大纲和清晰保存状态。
- **公共分发：** 停用个人数据快照导入，仅分发功能资源；快捷方式名称固定为 SciDesk。

## 使用范围

本次发布安装器已在 Windows 11（构建 26300）的独立临时标准账户中通过真实图形安装、首次启动／重启、正式 0.3.2 → 0.4.5 升级，以及同版本重装和阻止降级测试。升级保留合成用户文件、六个模块数据库业务数据和设置；原本机安装未改动。测试环境已有 WebView2，其他 Windows 版本和缺少 WebView2 时的联网安装尚未在本轮验证。详细范围见安装说明。

协作角色可由同一模型承担，这不等于独立模型交叉验证。不同服务商的图像和工具能力需以实际接口为准。进行中的 token 用量未返回时显示未知；文件结果以真实执行回执为准。Agent 不开放任意 Shell、SQL 或全盘访问；部分 PDF 文本提取路径仍依赖外部工具。

旧版安装包和历史发布记录保留；升级到新版后需要回退时，应使用匹配的升级前程序与完整数据快照，不能只换回旧 exe。
