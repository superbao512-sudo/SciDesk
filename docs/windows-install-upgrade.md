# SciDesk 0.4.5 Ai：Windows 安装与旧版升级

适用于 Windows 10/11 x64。开始菜单和任务栏中的名称为 **SciDesk**，具体版本在程序窗口或版本信息中查看。

## 下载哪一个文件

在 [0.4.5 Ai 发布页](https://github.com/superbao512-sudo/SciDesk/releases/tag/v0.4.5) 下载：

| 文件 | 用途 |
| --- | --- |
| `SciDesk_0.4.5_x64-setup.exe` | 普通用户使用的中文图形安装器，可双击安装或升级 |
| `SHA256SUMS.txt` | 核对发布文件是否下载完整；校验值不等同于发行者数字签名 |

GitHub 自动生成的 Source code ZIP/TAR 不是 Windows 安装程序。旧版的 `personal-setup.exe` 也不是 0.4.5 安装器。若另有 ZIP 覆盖更新包，它属于补充更新方式，需使用该包自己的说明，不与图形安装步骤混用。

安装包只包含程序、离线翻译模型、运行库、公共工具资源和许可。每位用户自行添加项目、学习资源、学术主页和模型配置；不会导入开发者的测试数据、个人配置或密钥。

本安装器尚未使用代码签名证书签名。请从本仓库正式发布页下载并核对 SHA-256；Windows 可能显示发行者未知。不要从不明来源下载同名程序，也不需要关闭系统防护。

## 首次安装

1. 双击 `SciDesk_0.4.5_x64-setup.exe`。
2. 按中文向导选择当前账户可写的安装目录，完成安装。程序会在其旁边使用 `SciDeskData` 保存运行数据，因此不建议选用无写入权限的目录。
3. 若电脑缺少 Microsoft Edge WebView2，安装时需要联网安装该运行环境。PDF 翻译权重已经随 SciDesk 提供，首次翻译不再下载权重。
4. 从开始菜单的 **SciDesk** 启动。添加或导入自己的项目；需要联网 AI 时，在模型设置中填写自己的服务地址、模型和 API 密钥。

新装软件没有开发者的项目、聊天或研究主页。公共功能目录、工具资源和模型许可属于程序的一部分。

## 从 0.3.2 升级

1. 保存手册、笔记等正在编辑的内容，退出 SciDesk 和它打开的分析工具。
2. 确认原安装路径。可以右键旧快捷方式，查看属性中的目标；目标中的 `scidesk.exe` 所在目录就是应使用的安装目录。
3. 双击新版安装器，核对并选择 **原安装目录**。例如原程序在 `D:\SciDesk\scidesk.exe`，就继续使用 `D:\SciDesk`，不要选其下的 `SciDeskData`。
4. 完成安装后启动 SciDesk，核对显示版本为 **0.4.5 Ai**，并查看原项目、想法、收藏、手册、学习资源和自己的模型配置。
5. 如果旧任务栏图标因 Windows 缓存仍显示「SciDesk 2.0」，取消该图标的固定，再从开始菜单的 SciDesk 重新固定。不要重新运行旧安装包。

无需先卸载旧版。安装程序更新程序和公共资源，已有 `SciDeskData` 保留；首次运行可能升级其中的元数据格式。外部项目和手册的科学文件仍留在原位置。

升级前可在退出软件后，将整个原安装目录复制到另一处，作为需要回退时的完整快照。图形安装器不会替你自动生成一份所有科研数据的全量备份。

## 更早的版本与个人安装包

若使用 0.3.1 个人安装包或手工移动过安装目录，请先通过旧快捷方式确认当前路径，再在新版向导中明确选择该路径；不要仅依赖安装器默认目录。新版不导入旧安装目录遗留的 `personal-seed`，也不自动删除它。已经属于用户的 SciDeskData 继续保留。

如果升级后看到空白项目列表，先核对是否误装到了另一目录，不要立即复制几个数据库文件或删除旧目录。程序旁的数据目录、WebView 缓存和外部关联文件应作为完整数据范围处理。

## 数据、迁移和回退

- **本机升级：** 安装目录保持不变，继续使用原 SciDeskData 和外部路径。
- **换电脑：** 退出软件后迁移完整 SciDeskData，同时迁移外部项目、手册或保证原路径可访问。Windows 保存的 API 凭据可能需要在新电脑重新输入。
- **删除会话：** 删除对话与审计记录不等于删除 Agent 已创建的业务成果。
- **回退旧版：** 新版可能升级数据库格式。先保存升级后的新工作，再恢复匹配的升级前完整程序和数据；不要只把新 exe 换回旧 exe，也不要混合不同时间点的数据库、WAL 和 SHM。
- **分享软件：** 分享发布页中的安装器及说明，不要压缩自己的整个安装目录或 SciDeskData 发给别人。

## 安装后检查

- 开始菜单名称为 SciDesk，程序版本为 0.4.5 Ai。
- 原项目路径、手册、收藏与个人设置可继续访问。
- 期刊推送「为我推荐」中，「立即更新」左侧出现「设置」，可调整最近文献区间。
- SciDesk Ai 可新建项目和会话，模型列表来自用户自己的设置。
- PDF 本地翻译无需下载模型；联网检索和自选 API 仍需要网络。

具体的新功能和限制见 [更新记录](../CHANGELOG.md)。安装或升级遇到问题，可在 [Issues](https://github.com/superbao512-sudo/SciDesk/issues) 提供版本、Windows 版本、安装路径及不含私人内容的错误提示；不要上传密钥、个人数据库或科研原始文件。

## 本次安装验收范围

本次使用同一份发布安装器，在 Windows 11 家庭版（构建 26300）的独立临时标准账户中运行真实安装流程；账户具有独立的注册表和用户目录。这属于账户隔离测试，不是虚拟机测试，也没有更新开发者本机的正式安装。

- 图形安装向导、首次启动、重启通过；新装没有个人项目、聊天或模型配置。
- 使用 GitHub 已发布的 0.3.2 安装器先安装旧版，再升级到 0.4.5。首次启动新版前，原 SciDeskData 文件字节保持一致；启动后六个模块数据库的原有业务数据、合成项目和文件、设置及凭据连续性检查通过。
- 同版本重装保留数据；尝试降级被阻止且没有修改数据。升级没有调用旧卸载器，安装目录中的未知用户文件保留。
- 使用 0.3.2 程序模拟旧「SciDesk 2.0」安装登记，验证旧路径识别与名称迁移。这不等同于对历史 0.3.1 个人安装包做过实际升级测试。
- 临时测试账户和配置目录已清理，原本机账户的安装登记及快捷方式保持不变。

本轮使用已有的 WebView2，未验证缺少该运行环境时的联网下载流程，也未覆盖 Windows 10 或其他系统构建。安装验收没有调用商业模型或真实文献服务，不代表所有模型接口和科研功能均完成端到端验收。
